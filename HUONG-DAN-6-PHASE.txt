ERP CỬA THÉP - NÂNG CẤP 6 PHASE
Baseline: cua-thep-demo(10).zip

=================================================
PHASE 1 - MATERIAL READINESS + SET READINESS
=================================================

Menu mới:
- Sẵn sàng vật tư: /material-readiness
- Sẵn sàng đủ bộ: /set-readiness

Material Readiness tại LSX Cha:
READY / PARTIAL / SHORTAGE / HOLD

Smart Planning sẽ loại các LSX:
- SHORTAGE
- HOLD
- Quality Hold

Nếu LSX chưa cấu hình Material:
- demo mặc định READY để không phá flow cũ.

Set Readiness:
- Cánh Ready = Good tại WO05
- Khung Ready = Good tại WO10
- Phào Ready = Good tại WO13
- Nếu WO terminal COMPLETED nhưng chưa có report chi tiết, dùng SL LSX.

SET READY theo từng LSX:
MIN(Cánh Ready, Khung Ready, Phào Ready)

Không cộng chéo Cánh của đơn này với Khung của đơn khác.

=================================================
PHASE 2 - BOTTLENECK ENGINE
=================================================

Menu:
/ bottleneck -> thực tế route: /bottleneck

Tính theo Lô:
- Cánh Gap
- Khung Gap
- Phào Gap
- Set Gap
- Bottleneck Branch

Đồng thời tính Capacity Load từng WO:
Planned / Capacity / Load % / Remaining

=================================================
PHASE 3 - SMART AUTO PLANNING
=================================================

Menu:
/smart-planning

Planning Score dùng:
- Ngày giao
- Priority Lô
- Material Status
- Bottleneck Branch
- Branch Gap
- Capacity còn lại của WO hiện tại

Chỉ lấy Lô:
RELEASED / RUNNING

Kết quả:
- LSX nào nên ưu tiên
- Nhánh nào
- WO nào
- SL đề xuất
- Score
- Lý do

Nút "Tạo & lưu Smart Plan":
- lưu production_planning_runs
- lưu production_planning_recommendations
- KHÔNG tự Release Dispatch
- planner vẫn kiểm soát Dispatch hiện tại

=================================================
PHASE 4 - SCHEDULE BOARD
=================================================

Menu:
/schedule-board

Ma trận:
WO x 7 ngày

Hiển thị:
Planned / Capacity
Load %
Overload
Remaining

Màu:
- xanh: bình thường
- vàng: >=90%
- đỏ: >100%

=================================================
PHASE 5 - QUALITY / HOLD / TRACEABILITY
=================================================

Menu:
/quality

Event:
QC / HOLD / REWORK / DEFECT / RELEASE

HOLD:
- tạo trace event
- block toàn bộ production_orders có cùng root_id
- blocked_reason = lý do Quality Hold

Release Hold:
- đóng các HOLD đang OPEN
- bỏ block LSX/WO
- tạo RELEASE event

=================================================
PHASE 6 - DASHBOARD KPI
=================================================

- Material Shortage / Hold
