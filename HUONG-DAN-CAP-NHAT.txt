=================================================
1. LOGIC VẬN HÀNH ERP
=================================================

Cập nhật đầy đủ 19 bước:
Order -> LSX -> Lot -> Material -> Routing/WO -> Capacity/WIP -> Priority
-> Set Readiness -> Bottleneck -> Smart Plan -> Schedule Board
-> Auto Dispatch -> Release -> Shop Floor -> Carry Over -> Đủ Bộ
-> Quality/Hold -> WO chung -> Dashboard/Re-plan.

Cập nhật Dispatch logic mới:
- Carry Over chiếm Capacity trước.
- WO đầu Cánh/Khung/Phào chạy theo Capacity còn lại.
- WO sau chừa WIP Buffer thiếu đến Target.
- WIP Max là cảnh báo, Capacity là giới hạn cứng.

=================================================
3. LẬP KẾ HOẠCH TỪNG BƯỚC
=================================================

Vẫn giữ 1 workspace, không chuyển trang trong flow thao tác.
Bước 4 được nâng thành Planning Intelligence:
- Material Ready / Shortage
- Set Ready / Set Gap
- Quality Hold
- WO Overload
- Bottleneck theo Lô
- Smart Recommendation / Score
- Planning Exception

Bước Dispatch hiển thị thêm Carry Over.

=================================================
4. CẢNH BÁO KẾ HOẠCH
=================================================

Phân loại cảnh báo:
- Delivery
- Material
- Set / Bottleneck
- Capacity
- Quality

Có filter và KPI theo từng nhóm.

=================================================
5. KẾ HOẠCH 7 NGÀY
=================================================

Nâng thành finite-capacity quick view:
- Tổng Planned
- Tổng Capacity
- Load trung bình
- WO-Day tải cao
- WO-Day Overload
- Nhận diện nhánh Cánh / Khung / Phào / Đủ Bộ
- Link sang Schedule Board

Ngưỡng hiển thị:
0%: chưa có kế hoạch
< 90%: còn dư năng lực
90-100%: tải cao
> 100%: Overload cần reschedule
